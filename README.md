# Kala Yatra

An interactive, frontend-only timeline of landmark Indian art, built with React, TypeScript, Vite, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Import the repository into Vercel. The included `vercel.json` uses `npm run build` and deploys Vite's `dist` directory. No environment variables or server configuration are required.

Artwork and audio credits are visible within the exhibition and link to their source collection records.
